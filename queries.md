# Test queries

These 5 queries are used to test every search method in Parts 2–5.
Each one targets a different topic, so the tests cover several unrelated areas.

`embed.py` reads the numbered lines below, so keep each query on one numbered line.

1. any plans for new space exploration by a space agency
2. how far can I expand the RAM in my PC
3. the most powerful car engine with the highest top speed
4. what is the story of Adam and Eve
5. a good dealer to buy a 600cc motorcycle

Topics each query is expected to match (in order):

- sci.space
- comp.sys.ibm.pc.hardware
- rec.autos
- soc.religion.christian (possibly also alt.atheism, talk.religion.misc)
- rec.motorcycles (possibly also misc.forsale)
